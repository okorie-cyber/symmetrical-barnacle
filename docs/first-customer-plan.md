Goal: one paid Fix Sprint. Everything else is secondary.

## Honest conversion maths

Cold outreach to small contractors typically produces low single-digit reply rates. With a personalised audit, a realistic guess is:

> 20 contacts → 1 to 3 interested replies → 0 or 1 sale

**So 20 prospects is a validation batch, not a guaranteed sale.** Plan for 60 to 100 personalised contacts over about 3 weeks to land the first payment. The audit cost per extra prospect is about $0, so scaling the list is cheap; your time is the constraint.

## Spending requests

**None are required to reach the first customer.** Two optional items, explained as you asked:

### Optional 1: business domain (~$10 to $15/year)
- **What for:** a sending address like name@yourbrand.com and a landing page address
- **Why:** emails from a student Gmail address look less credible to a US contractor
- **Cheaper alternatives:**
  - Send the first 20 from a clean Gmail with your real name and a clear signature (free)
  - Host the landing page on GitHub Pages (free; needs a public repo)
- **Expected result:** a modest reply-rate lift. Unmeasured, so we'd test it: first 20 from Gmail, next 20 from the domain.

### Optional 2: OpenAI API (~$5 to $10 for the 20-prospect batch)
- **What for:** automating the ChatGPT approximation instead of copy-pasting
- **Why:** saves about 1.5 hours per batch
- **Cheaper alternative:** manual capture (free, and more faithful because it is the real app)
- **Expected result:** time saved, not accuracy gained. Only worth it once we're auditing 50+ prospects a week.

**Not recommended now:** cold-email software, paid tools, Stripe Atlas, ads.
